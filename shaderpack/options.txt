# One option per line: DEFINE | Label | kind | default | optional help
# kind = bool | enum value:Label ... (use _ for spaces) | range min max step
# "@ Name" creates a category tab. Changes are saved and hot-reloaded.

@ Profiles
!PROFILE_SAVE | Save current settings as... | action | 0 | Enter a name in the field above while holding Alt, then press Enter or click Save name. Existing profiles are never overwritten.
!PROFILE_EXPORT | Export saved profile | action | 0 | Apply a saved custom profile, then export it as a shareable GLSL file in shaderpack/presets/exports. Includes its name and settings. Existing exports are never overwritten.
!PROFILE_DELETE | Delete saved profile | action | 0 | Apply a custom profile, then delete and confirm within five seconds. Current settings and exports stay. Default and quality presets cannot be deleted.
!PROFILE | Quality profiles | list | -1 | Click a profile or press Right to apply it. RTX uses DLSS Quality+ at 77% with RR when supported. Non-RTX uses native resolution with DLSS off. Both offer Lowest through Ultra.
